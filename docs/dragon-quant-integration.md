# dragon-quant 龙头策略集成说明

## 集成范围

本项目以 L2 源码扩展方式集成 `gitBingxu/dragon-quant` 0.5.1 的以下算法：

- 五维真龙评分：带动性 30%、领涨性 25%、抗跌性 15%、流动性 20%、资金承接 10%。
- 硬门槛：带动性 40、领涨性 40、抗跌性 35、流动性 35；任一维度不足即不认证为真龙。
- 账户策略：近 3 个扫描交易日真龙池、分歧买龙、MA5 开盘承接、突破前高弱转强、T+1、首日/后续止损、移动止盈、保本、次日涨停卖半仓、弱势和放量退出。

未移植源项目 `review.py` 的“事后最低价买入”验证逻辑，因为该价格在交易决策时不可获得。账户回测使用逐交易日推进的历史扫描记录，不读取未来扫描结果。

## 接入位置

- 后端扩展：`backend/app/custom/dragon_quant/`
- 前端扩展：`frontend/src/custom/dragon_quant/extension.tsx`
- 页面路由：`/dragon-quant`
- API 前缀：`/api/custom/dragon-quant`
- 用户记录：`data/user_data/dragon_quant/scans.json`、`backtests.json`

扩展不修改 `StrategyEngine`、`BacktestEngine` 或核心路由。未启用或加载失败时，不影响原有策略库和回测功能。

## 数据源与字段口径

本集成不使用 dragon-quant 自带的雪球 Cookie、同花顺、腾讯或 Playwright 数据链路，全部数据来自 tick-stock-panel：

| 策略输入 | 当前项目数据 |
| --- | --- |
| 个股日线、MA5、连板、成交额、换手率 | enriched 日线仓库 |
| 个股分钟线 | 股票分钟分区；候选及有限行业样本缺失时通过当前分钟 Provider 按需补取 |
| 行业归属 | 扩展数据中的行业字段 |
| 行业排行 | 行业内成分股当日涨跌幅等权平均 |
| 行业分钟线 | 每个候选相关行业最多 10 只高成交额成分股相对昨收涨幅等权聚合，候选股强制纳入 |
| 市场分钟线 | 上证指数 `000001.SH` 相对昨收涨幅 |
| 历史资金承接 | 领涨/领跌行业成分股的 5 分钟等权聚合 |
| 收盘封单 | `DepthService` 封单快照 |

单位保持当前项目契约：`change_pct` 为小数制，enriched `turnover_rate` 为百分数值，日线 `volume` 与盘口封单量均为“手”。涨停候选和涨停价使用原始昨收、交易日期和板块价格限制规则，不以复权价格判断。

## 数据完整性门控

评分可以在部分输入缺失时给出用于诊断的分数。真龙认证只对关键输入采用 fail-closed：

- 候选股分钟线缺失；
- 候选相关行业的分钟样本不足；
- 上证指数分钟线或昨收基准缺失；
- 行业映射不存在或无法与当日日线匹配。

关键分钟缺失时会保留 `score_passed`，同时强制 `is_true_dragon=false` 并返回 `critical_missing`；行业映射完全不可用时扫描直接返回业务错误。五档封单缺失放入 `optional_missing`：流动性维度沿用源策略对涨停且无盘口使用 60 分中性值的降级逻辑，最终仍由流动性总分和 35 分硬门槛决定。历史资金承接分钟数据同样放入 `optional_missing`，沿用源策略无事件时 50 分的降级值，因为资金承接维度只参与加权、不参与四项硬门槛。账户回测只读取 `is_true_dragon=true` 的历史记录。

按需补取不等同于全市场分钟同步：扫描只读取候选股和每个相关行业的有限样本，避免对不支持全市场分钟同步的逐标的 Provider 发起数千只股票请求。扫描最新 enriched 交易日时，若本地没有可用封单快照，会调用当前五档 Provider 立即补拉并落盘；历史五档盘口无法由实时源补造，过去日期没有已保存快照时按中性值降级，绝不使用当前盘口冒充历史数据。

## 与源项目结果的差异

源项目使用同花顺官方行业指数分钟线及其行业排行，本集成使用当前项目有限行业样本等权聚合，并使用上证指数作为市场基准，因此行业脉冲、市场基准和资金承接分数不会逐点完全一致。盘口快照的采集时点、分钟数据覆盖范围和行业映射版本也会影响最终认证结果。页面和扫描记录会显示实际行业源、分钟行数、适配说明以及关键/可选缺项，避免把降级结果描述成源项目的完全复现。

## 回测边界

- 买入仅使用买入日前已经保存的扫描，默认回看 3 个交易日。
- 当日买入不可当日卖出，首个可卖日为下一交易日。
- 计入买卖滑点、佣金和卖出印花税，股票数量按 100 股整数手处理。
- 缺少历史扫描时默认给出 warning 并保持空仓；可显式开启自动补扫，单次最多补 20 个交易日。
- 日线条件按开盘或收盘价成交；分歧买龙只有在分钟数据存在时才启用盘中确认。
